# syscheck

A simple Bash CLI tool that checks basic system info and creates a timestamped backup.

## What it does
- Shows current date and time
- Shows current folder
- Lists files in the folder
- Shows disk usage
- Creates a compressed, timestamped backup of the script

## How to run
```bash
bash syscheck.sh
```

## Why I built this
Built this to practice Bash scripting, file permissions, and automation basics on Linux/Git Bash.
